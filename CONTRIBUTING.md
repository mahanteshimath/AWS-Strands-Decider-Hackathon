# Contributing to TariffTrail

Thanks for your interest. TariffTrail is a small, evidence-first project: an agent that classifies products into US
tariff codes, plus a reusable decision pattern ([PATTERN.md](PATTERN.md)). Contributions that make the pattern more
reusable, the evaluation more honest, or the demo clearer are very welcome.

## Ways to help

- **Try the pattern on another tree** (runbooks, ticket routing, ICD codes) and open an issue with what you measured.
  A `examples/<your_domain>/` folder with a small labelled test set and a `RESULTS.md` is the ideal shape.
- **Report evaluation problems:** a label that looks wrong, a possible leak between the retrieval index and the test split,
  a number in the README that you cannot reproduce.
- **Fix bugs and improve docs.** Start with anything tagged `good first issue`.

Please open an issue before starting anything larger than a small fix so we can agree on the approach.

## Development setup

```bash
git clone https://github.com/mahanteshimath/AWS-Strands-Decider-Hackathon.git
cd AWS-Strands-Decider-Hackathon
pip install uv && uv sync --extra dev        # Python 3.11+
python data/fetch_hts.py                     # optional: enables the tests that need the HTS
uv run pytest
```

You do **not** need a GPU, Strands Decider, or an AWS account to run the tests or the recorded-run demo: the pattern
tests use a fake Decider.

## Pull request checklist

- [ ] `pytest` passes.
- [ ] New behaviour has a test (the pattern tests use a fake Decider; see `tests/test_tree_descent.py`).
- [ ] Any number you add or change in the README, article or results is reproducible from a script in `eval/`, and you
      say how in the PR description.
- [ ] If you touched `docs/architecture/build_diagrams.py`, regenerate the diagrams (below) and commit the `.drawio`
      and `.drawio.png` files. CI fails if the committed `.drawio` files differ from the generator output.
- [ ] No secrets, AWS account IDs, or personal data. `.env` is git-ignored; keep it that way.

## Evaluation rules (please keep these)

The headline results were measured **once** on a held-out split with a configuration frozen in
[`research/PREREGISTRATION.md`](research/PREREGISTRATION.md). To keep that meaningful:

- Do not tune on `data/eval/test.jsonl`. Use the `dev` split.
- If you change the method, report the new numbers as a *new* result next to the frozen one; do not overwrite it.
- Report invented-code rate and token cost alongside accuracy; accuracy alone hides both.

## Style

Python 3.11+, type hints, small functions, and comments only where the reason is not obvious. Match the surrounding code.
Use plain, specific language in docs and avoid claims you have not measured.

## Regenerating the architecture diagrams

The diagrams are draw.io files generated by `docs/architecture/build_diagrams.py`. See
